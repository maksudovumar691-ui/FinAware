FinAware:

FinAware — образовательный веб-сайт, 
посвящённый финансовой грамотности молодого поколения.

Проект направлен на повышение осведомлённости о 
разумном управлении личными финансами, 
формировании полезных финансовых привычек и 
предотвращении импульсивных покупок.

Цель проекта:

Помочь молодым людям лучше понимать принципы
финансовой грамотности, осознаннее относиться к 
расходам и принимать более взвешенные финансовые решения.

Основные разделы

-О проекте — описание FinAware и его задач.
-Почему финансовая грамотность важна — значение финансовых знаний в повседневной жизни.
-Исследования и статистика — данные и материалы о финансовой грамотности.
-Финансовые советы — практические рекомендации по управлению деньгами.
-Импульсивные покупки — причины необдуманных расходов и способы их предотвращения.
-Цифровая безопасность — основы безопасного поведения в финансовой среде.
-Тест — интерактивная проверка знаний по финансовой грамотности.

Используемые технологии:

- HTML5 — структура веб-страниц.
- CSS3 — оформление, адаптация интерфейса и анимации.
- JavaScript — интерактивные элементы и логика тестирования.

Особенности:

- Современный интерфейс в тематике финансовых технологий.
- Анимированные декоративные элементы.
- Интерактивные карточки и визуальные эффекты.
- Тест из 10 вопросов.
- Плавное появление элементов при прокрутке страницы.

Запуск проекта:

Проект не требует установки серверного программного обеспечения.

1. Скачайте или клонируйте репозиторий.
2. Откройте папку проекта.
3. Запустите файл `index.html` в браузере.

Структура проекта:

FinAware/
│

│── script.js
